# CharLS - JPEG-LS Reference Implementation

This directory is intended for the CharLS JPEG-LS reference implementation.

## Setup
Please download the latest release from [https://github.com/team-charls/charls/releases](https://github.com/team-charls/charls/releases) and place the `charls` executable (and any required DLLs) in `../bin/`.

## Usage
Used for interoperability testing of JPEG-LS encoding and decoding.
